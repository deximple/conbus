What it records

A local recorder hooks each agent and keeps one append-only log per machine. From it you get, per day and per harness:

  • where runs stopped, filed by cause — a limit, the account, the vendor, a request, or a person
  • tool failures and interrupts
  • permission waits — where an agent sat idle for a person's answer
  • attended vs unattended runs — the unattended ones are the ones that fail silently

Works with Claude Code, Codex, Cursor, grok and opencode.

Into the monitoring your team already runs

The recorder can emit its normalised counts as OpenTelemetry into a collector on your own machines — Datadog, Grafana, whatever you run. conbus holds no keys and sees no dashboards.

Local policy, before the tool runs (experimental)

A policy.json on the machine turns into deny/ask decisions through each vendor's own hook mechanism — evaluated in the hook process, so a down recorder cannot lift a deny. No rule ever comes from a server.

macOS and Linux

One binary. On macOS it registers as a launch agent; on Linux and CI, a systemd user unit or a foreground process.

Privacy: counts only

Nothing shareable can carry a prompt, a path, a command, or an error text. conbus usage --shareable prints the exact rows a sync would send — read the payload before it could ever leave.
