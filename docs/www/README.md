# conbus.sh

Public name: **conbus.sh**. `conbus.io` and `conbus.ai` were open when
checked; they are alternates, not the brand. `conbus.com` is taken (2008).

This directory is the landing. DNS and hosting are operator steps and
are not required to review the page in the repo.

`index.html` is self-contained — its own styles, one small script for the copy
buttons, fonts from Google Fonts — so it can be served as it is. Every command
and output line on it is real conbus 0.1.1 behaviour; ids and times in the
examples are made up, and the briefing counts are from the author's machine.
Documentation links point at the GitHub repository, so they work only once it
is public.
