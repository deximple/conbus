A local conversation bus for coding agents

The conversation stays. The harness changes.

conbus files every prompt, reply and tool call from Claude Code, Codex, Cursor, grok and opencode into one log on your Mac, under one id per conversation. A new session is told what the last ones were doing, and when a limit stops a turn, the next agent can take the conversation from there.

curl -fsSL https://raw.githubusercontent.com/deximple/conbus/main/install.sh | sh

Checks the release's SHA-256, then changes nothing in your agents' settings until you run conbus install --apply. macOS, Apple silicon and Intel.

The route, in the order you meet it

Stop 1 · Install

Two commands and one yes.

The installer places the binary and shows what it would register. conbus install --apply merges one hook into each agent installed on this Mac — never into one you don't have — keeps a copy of every file it touches, leaves your own hooks exactly where they were, and starts the recorder.

Codex asks you once to approve those hooks. conbus never approves them for you.

$ conbus install --apply
claude_code  ~/.claude/settings.json — would register SessionStart, …
             written; previous copy at ~/.claude/settings.json.conbus-backup
codex        ~/.codex/hooks.json — would register SessionStart, …
             written (the file did not exist)
grok         not found (no ~/.grok) — skipped
daemon       ~/Library/LaunchAgents/sh.conbus.daemon.plist
             written

Stop 2 · Record

Every turn, every agent, one log.

Prompts, replies, tool calls, permission asks and quota stops land in ~/.conbus as append-only lines, each under its conversation's id. Tool inputs and outputs are not written unless you ask for them.

A hook waits at most 500 ms for conbus, then lets the record go and says so. Your agent never waits on conbus.

$ conbus log --bus-id 01a0c7f2 --tail 4
2026-09-22T05:02:11.418Z  96521 01a0c7f2-… claude_code turn-started
2026-09-22T05:02:19.006Z  96534 01a0c7f2-… claude_code tool Read requested
2026-09-22T05:02:19.012Z  96535 01a0c7f2-… claude_code tool Read (6ms)
2026-09-22T05:37:03.120Z  96611 01a0c7f2-… codex turn-started

Example records. The log keeps time in UTC.

Stop 3 · Brief

A new session starts where the last one was.

Open a session in a project and conbus tells it, through the agent's own context channel, what the recent conversations there were doing — whichever agent they ran on. At most three conversations and 2,600 characters, whole or not at all.

Scheduled jobs and scripts are not briefed. CONBUS_BRIEFING=off turns it off for you.

$ conbus doctor
briefing  6480 conversation(s) judged
             169  brief
             452  silent/arrived_with_context
             238  silent/nothing_to_say
            5348  silent/unattended
               …
             2.0  conversations named per briefing (cap 3)

From the author's machine: most sessions there are programs, and programs are left alone.

Stop 4 · Hop

A limit is a transfer, not a dead end. Experimental

When a vendor stops a turn for quota, conbus can move the conversation to the next agent under the same id — Claude Code and Codex to each other, the rest to Codex — into a session it has kept warm. Or point it yourself: conbus go cursor, or just type switch to cursor.

Run your agent under conbus run and the next one starts in the same terminal.

In 0.2.5 the hop has worked in probes and on request. It has not yet been seen acting on a real limit.

$ conbus status
history   2026-09-22T05:37:02.771Z  96610 01a0c7f2-… claude_code
          routed Displaced → codex (rate_limit)
history   2026-09-22T05:37:03.120Z  96611 01a0c7f2-… codex
          continued Displaced from 01a0c7f2-…

Example history, wrapped to fit.

Stop 5 · Take it back

Leave the way you came.

conbus uninstall --apply takes out every hook it added and nothing else, puts your status line back, and deletes its own files. Your log stays until you delete it — it is your record, not ours.

$ conbus uninstall --apply
claude_code  ~/.claude/settings.json — removed SessionStart, …, StatusLine
             written; previous copy at settings.json.conbus-uninstall-backup
daemon       sh.conbus.daemon.plist — stopped and deleted
data         ~/.conbus — kept. It is your log; remove it yourself if you want it gone

Abbreviated output.

What stays on your Mac, and what does not.

Stays here

The log, in ~/.conbus. There is no conbus server, no account and no telemetry.

Vendor sign-ins and tokens are never read. Quota comes from what the agents already report to their own tools.

Goes to an agent, as context

A briefing, the conversation so far when a hop lands, and conbus summary when you run it. That is text from your own log, sent to the agent you are using, the way anything you type is.

Service notes

  • opencode

Use the ones you have; conbus registers only those.

  • macOS only, for now.
  • Claude's remaining quota is visible only from the terminal claude; its desktop app never reports it.
  • The automatic hop has not met a real limit yet.
  • Codex asks you to approve conbus's hooks once.
  • Not notarized yet. The installer downloads with curl, which macOS does not quarantine.
  • The repository is private for now, so installing needs GitHub access.
