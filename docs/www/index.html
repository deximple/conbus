conbus.sh

The conversation stays. The harness changes.

Conbus is a local conversation bus for coding agents. Vendor TUIs stay the window. The bus owns the id, the log, and the hop.

A limit mid-task is a routing event, not a new chat. The next Claude or Codex leg opens on a bus-owned warm. A chat line that is only an order, or conbus go cursor, is a directed hop. Cursor opens the checkout with official cursor -n.

curl -fsSL https://raw.githubusercontent.com/deximple/conbus/main/install.sh | sh
conbus install --apply
conbus doctor
conbus hop --demo
conbus run claude_code

The script checks the release's SHA-256 and changes no vendor settings; install --apply does, and conbus uninstall --apply takes it all back out and keeps your log. macOS only. The repository is private for now, so a release installs only for people signed in to gh with access.

License: Apache-2.0. Local only: no hosted service, no telemetry, and the bus never reads vendor auth tokens. Codex trust is a gesture inside Codex; we do not write that hash. Put ~/.local/bin on PATH if conbus is not found.

Domain decision: conbus.sh is the public name. Registration is an operator action; this page is the landing that ships with the repo. Hook contract: RFD 0001. First-time path: beginner manual.
